# security-privacy-guidelines
セキュリティとプライバシーを守るための推奨事項をまとめたガイド。
これは未完成で嘘も含まれています。

セキュリティに関連するものは🔒️
プライバシーに関連するものは🕵️
匿名性に関連するものは 🎭


個人が日常的にできる、端末・アカウント・ネット利用の基本的な対策をまとめています。

すべてのリスクをなくせるわけではありませんが、次の習慣で被害に遭う可能性を下げられます。
セキュリティとプライバシーは時に背反することもあるのでその場合は分岐的に紹介します。

## まず守ること

- OS、ブラウザー、アプリを最新の状態に保つ
- サイトごとに異なるパスワードを使う
- 重要なアカウントでは多要素認証を有効にする
- 求められていないアプリ、ファイル、コマンドを実行しない
- 不安をあおる警告や急かす連絡には、すぐ反応しない


## まず導入するツール

一度にたくさん入れる必要はありません。まずは上から順に整えます。
アプリや拡張機能は、必ず公式サイトまたは公式ストアから入手してください。

### パスワードマネージャー（最優先）🔒️

例：Bitwarden、Proton Pass、KeePassXCなど。どれか1つを選びます。自己管理できるならKeePassXCを選ぶこと 

- サイトごとに異なるランダムなパスワードを作り、保存する
- マスターパスワードは長く、他のサービスでは使わない
- パスワードマネージャーのアカウントにも多要素認証を設定する
- 復旧方法を確認し、必要な復旧コードは安全な場所に保管する
- 自動入力が出ても、それだけでログインページが本物だと判断しない
- 重要なパスワードはURLの検出方法を完全一致にする
- 特別な理由がなければ「ベースドメイン」は避ける。サブドメインにも候補が出る。

### パスキー・多要素認証🔒️

例:パスキーならBitwarden(有料プランのみ)、OneKeePass、Proton Passなど
例:認証アプリ（TOTP）ならEnte AuthやProton Authenticator、Aegisを選ぶ

- 対応しているサービスでは、まずパスキーの利用を検討する
- パスキー設定時はパスワードからのログインはOFFに
- パスキーが使えない場合は、多要素認証を有効にする
- 認証アプリのコードを使う場合は、認証アプリ（TOTP）を導入する
- メールアカウントやパスワードマネージャーなど、重要なアカウントから設定する
- 復旧コードを端末とは別の安全な場所にオフラインもしくはゼロ知識証明ありのクラウドストレージに保管する

###  ブラウザとコンテンツブロッカー

##### おすすめのブラウザ

セキュリティ重視順に
- Trivalent(Linux)
- Brave with SlimBrave-Neo
- Helium
- Firefox強化版
- Mullvad Browser

プライバシー重視順に
- Tor Browser
- Mullvad Browser
- Firefox強化版
- Helium
- Brave＋SlimBrave-Neo
- Trivalent


- Firefoxでは、公式配布元から [uBlock Origin](https://github.com/gorhill/ublock) を導入する
- Chromeでは、ブラウザーが対応している[AdGuard](https://chromewebstore.google.com/detail/adguard-adblocker/bgnkhhnnamicmpeenaelnjfhikgbkllg?hl=ja)か[uBlock Origin Lite](https://github.com/uBlockOrigin/uBOL-home)を選ぶ
- uBlock Originが使えるChromiumブラウザである[Helium](https://helium.computer/)を使うことも検討する。
- 拡張機能の提供元と権限を確認し、似た名前のものを入れない(uBlockなど)
- ブロッカーはWeb閲覧時の補助策。アプリ内広告や危険なファイルをすべて防げるわけではない
- 複数のブロッカーを同時に入れない。(ただし[SponserBlock for YouTube](https://sponsor.ajay.app/)はカウントしない)

### OS

おすすめのOS
特に理由がないならGrapheneOSを使う。対応していない機種ならiodé0Sを使う。古い端末でサポート切れならLineage0Sを使うか破棄すること。
- [GrapheneOS](https://grapheneos.org/)🔒️⭐️⭐️ - セキュリティとプライバシーを重視したAndroidベースのOS。アプリごとのネットワーク・センサー・ストレージ・連絡先権限を細かく制御でき、Google Playも通常のアプリと同じサンドボックス内で利用可能。強化されたメモリ保護、自動再起動、Verified Bootやブートローダーの再ロックなどにも対応。
- [iodéOS](https://iode.tech/iodeos/)⭐️ - LineageOSをベースにした、広告・トラッカー対策重視のAndroid ROM。アプリごとの通信先を監視・遮断できるファイアウォールを搭載し、microGにも対応。Googleサービスへの依存を減らしながら、Pixel、Fairphone、Samsung、Xiaomiなど幅広い端末で利用できる。
- [LineageOS](https://lineageos.org/) - AndroidをベースにしたオープンソースのカスタムOS。メーカー製アプリなどを減らした軽量でクリーンなAndroidを使え、古い端末にも新しいAndroidやセキュリティアップデートを提供。
- [CalyxOS](https://calyxos.org/) - プライバシーを重視したAndroidベースのオープンソースOS。オプションのmicroGを利用でき、Google Play依存を減らしつつ普段使いしやすい構成。Verified Bootやブートローダーの再ロックにも対応

- 自動更新を有効にする

### メールエイリアス

- 登録先ごとに異なるメールアドレスを使いたい場合は、メールエイリアスを利用する
- 迷惑メールや情報流出の発生元を見分けやすくなる
- エイリアスの管理サービスにログインできなくなった場合の復旧方法も確認する
- メールエイリアスは、本人特定や追跡を完全に防ぐものではない

### アプリのトラッカー確認ツール（Android）

例：Exodus Privacy

- アプリに含まれる既知のトラッカーや権限を調べる参考にする
- 検出結果だけでアプリの安全性を断定しない
- 権限、開発元、配布元、更新状況もあわせて確認する

### 導入するときの共通ルール

- インストール前に、配布元と開発者名を確認する
- 必要以上の権限を求める場合は、理由を確認する
- 「オープンソース」「公式ストア掲載」「LLMが安全と評価」だけで、安全性を断定しない
- 便利さと引き換えに、アカウント・端末・閲覧データへのアクセスを許可していないか確認する


## Webサイト・ファイルの利用

- 「専用プレーヤー」「コーデック」などのインストールを求められたら、ページを閉じる
- 動画や文書に見せかけた実行ファイルを開かない。拡張子を表示し、`.exe`、`.scr`、`.lnk` などには特に注意する
- 「ロボットでなければ許可を押す」などの指示で、ブラウザーの通知を許可しない
- 「登録完了」「料金請求」などの表示が出ても、表示された番号に電話したり、支払ったりしない


## アプリ・ソフトのインストール


- 開発元やアプリの用途を確認し、必要以上の権限を求めていないか確認する
- 電話やチャットの相手に誘導されて、遠隔操作アプリや画面共有を開始しない
- 使っていないアプリやソフトは削除する
- - 「高速化」「ウイルス除去」などをうたう、出所不明のソフトを追加で入れない

## ログイン・パスワード

- サービスごとに異なる、長く推測されにくいパスワードを使う
- パスワード管理アプリなどを利用し、パスワードを使い回さない
- メール、パスワード管理アプリ、金融サービスなどの重要なアカウントには、多要素認証を設定する
- 対応しているサービスでは、パスキーの利用も検討する
- 認証コードやログイン承認の通知を、他人に渡したり、心当たりのない操作で承認したりしない
- 復旧コードは、端末やパスワード管理アプリとは別の安全な場所に保管する

## メール・SMS・検索結果

- メールやSMSのリンクからログインしない。公式アプリや、自分で登録したブックマークから開く
- 差出人名やロゴ、鍵マーク（HTTPS）だけで本物と判断しない
- 心当たりのない添付ファイルやQRコードを開かない
- 検索結果の広告や、検索結果に表示された電話番号をそのまま信用しない
- 通知や漏洩のお知らせを受け取った場合も、リンクは開かず、公式サイトや公式アプリで確認する

## ブラウザー拡張機能

- 拡張機能は必要なものだけを入れる
- 開発元、更新状況、求められる権限を確認する
- 「すべてのサイトのデータを読み取り、変更する」権限には特に注意する
- 不要になった拡張機能は削除し、定期的に一覧を見直す
- 広告・トラッカー対策の拡張機能を使う場合も、それだけで安全が保証されるわけではない

## OS・ネットワーク

- OS、ブラウザー、アプリ、ルーターの更新を放置しない
- サポートが終了したOSや端末は、更新や買い替えを検討する
- 公共Wi-Fiでは、接続先やログイン画面をよく確認する
- HTTPS通信でも、偽サイトへの入力や詐欺そのものは防げない。重要な操作は公式アプリや正しいブックマークから行う
- 正体や運営元が分からないVPNアプリを安易にインストールしない

## 偽の警告・不審な操作指示

- 「ウイルスに感染した」「今すぐ電話」などの警告画面に表示された番号へ電話しない
- 警告画面の指示で、ソフトのインストール、送金、ギフトカードの購入をしない
- Webページの指示で、キー操作をしたり、コマンドをコピーして実行したりしない
- 偽の警告画面が出ても、慌てて電話や支払いをせず、ブラウザーを閉じる。閉じられない場合は、タスクマネージャーなどから終了するか端末を再起動する
- 警告画面が表示されたことだけで、端末が感染したとは限らない

## 自動操作AI・画面共有

- 自動操作AIに、重要なアカウントや金融サービスの操作を任せない
- AIや遠隔操作ツールに、必要以上のファイル・アカウント・端末へのアクセス権を与えない
- 面識のある相手からの依頼でも、認証コードや画面共有を求められたら別の方法で本人確認する

## 情報漏洩・被害に気付いたら

1. 怪しい端末はネットワークから切断する
2. 金融情報を入力した場合は、銀行やカード会社の公式窓口にすぐ連絡する
3. 認証情報を入力した場合は、安全な別の端末からパスワードを変更する
4. 同じパスワードを使っていたサービスでも、すべて変更する
5. 必要に応じて、サービスの公式窓口、警察、消費生活センターなどに相談する
6. 遠隔操作や不審なソフトのインストールがあった場合は、自己判断で使い続けず、専門窓口に相談する

## 更新について

このガイドは一般的な対策をまとめたものです。OSやサービスの仕様、攻撃手口は変化するため、具体的な手順は各サービスや公的機関の最新案内も確認してください。
